# worthwatch

worthwatch checks the YouTube channels you follow and tells you which new videos are worth your
time. It judges each one against a short file you write about your own projects, so the answer
is about you, not about the video's view count.

## Install

```
uv tool install worthwatch
worthwatch init
worthwatch doctor
```

`worthwatch init` makes your folders, copies an example context file for an invented person,
and asks which brain should do the judging. `worthwatch doctor` checks everything a run needs
and says in plain words how to fix anything missing.
